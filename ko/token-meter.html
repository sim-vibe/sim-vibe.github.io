Token Usage for Claude가 뭔가요?

Token Usage for Claude는 Claude Code의 토큰 사용량을 메뉴바에서 실시간으로 보여주는 macOS 앱입니다. 5시간 세션과 주간 한도를 Claude Code의 /usage 명령과 동일한 데이터로 확인합니다.

Token Usage는 무료인가요?

네. Token Usage for Claude는 Mac App Store에서 무료로 내려받을 수 있습니다.

Claude Code가 필요한가요?

네. Token Usage는 Claude Code의 /usage와 동일한 사용량 데이터를 읽기 때문에 Claude Code가 설치·로그인되어 있어야 합니다. 내장 데모 모드로 샘플 데이터를 미리 볼 수 있습니다.

내 데이터는 안전한가요?

네. Token Usage는 Mac 안에서만 동작합니다. 계정도, 자체 네트워크 통신도, 추적도 없으며, 로컬의 Claude Code 사용량 데이터만 읽습니다.

어떤 macOS 버전이 필요한가요?

Token Usage는 macOS 13.0(Ventura) 이상이 필요합니다.
